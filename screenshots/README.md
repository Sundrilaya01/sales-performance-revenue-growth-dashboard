## 3. How to Produce Live Desktop Screenshots
Upon importing the data model and theme into local **Power BI Desktop**:
1. Open `Sales Performance & Revenue Growth Dashboard.pbix`.
2. Follow the visual placement coordinates in [`docs/dashboard_layout_specification.md`](file:///d:/Power%20BI/Sales%20Performance%20&%20Revenue%20Growth%20Dashboard/docs/dashboard_layout_specification.md).
3. Capture live full-screen screenshots using Windows Snipping Tool (`Win + Shift + S`).
4. Save the real captures as `screenshots/live_executive_overview.png` and replace or accompany this mockup.
